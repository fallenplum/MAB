# MAB 模型组合路由中的并列监督与共享参数效应

本仓库研究语言模型路由中的一个具体问题：**当有限次生成得到的经验奖励并列时，训练目标怎样改变共享预测器的参数、其他问题的动作排序，以及最终答案质量。** 原始系统在六个冻结模型中选择三个，形成 20 个组合，由固定聚合器输出答案；路由器在生成前只读取问题表征。

当前论文主线为 E17–E22 的机制研究。现有证据支持：经验全并列训练行产生的对称损失项能够改变共享参数方向，并改变未参与拟合题目的严格动作排序。关闭这类约束在原系统的独立评价中改善了准确率，但跨损失和外部单模型池的质量收益没有一致方向；同权重匹配控制也未确立全并列行定向降权的特殊质量优势。**这里呈现受控机制及其适用边界，不将其表述为已获普适收益的新路由算法。**

论文仍在整理，目标会议为 ACL。本仓库不代表已经投稿、接收或公开发表。

## 核心设定与对照

原模型池为六个冻结语言模型，动作是从中选取三个成员的无序组合。成员独立回答后，由冻结的 Qwen3-8B 聚合器输出最终答案。主要奖励为最终答案的正确性；候选中出现正确答案只是一项辅助诊断。

E19–E22 原系统使用冻结 MiniLM 表征、训练区拟合的 PCA16 和标准化、一个截距以及 17×20 线性头。训练参数共 340 个。E21 外部实验改为六个单模型动作，每个任务各拟合一个头，它不是第二套三模型聚合系统。

设 T 为训练区中所有动作经验平均奖励完全相同的问题集合。B/C 两个端点保留相同训练问题、原始归一化分母、表示、函数类和正则，只改变 T 中行的损失权重：

| 端点 | 全并列行权重 | 其他训练行权重 | 含义 |
|---|---:|---:|---|
| B，β=1 | 1 | 1 | 保留对称约束 |
| C，β=0 | 0 | 1 | 关闭该约束，原归一化分母不变 |

经验全并列不等于真实条件期望完全相同。全并列行没有指定哪个动作更好，但它仍可能约束预测分差；共享参数使这项约束影响其他问题。E22 进一步使用同总权重均匀降权和三份预固定匹配随机掩码，检验质量变化是否特属于全并列行。

## 当前主要结果

准确率和点差均来自相应阶段的冻结策略。不同数据角色、模型池和损失的数值分别解释，不混成一张算法排行榜。

| 阶段 | 评价范围 | 主要观察 | 解释范围 |
|---|---|---|---|
| E17 | 原 600 题开发池 | 100 次重编号后，坐标冠军 SPO+ 的真实组合一致率均值约 6.13%；Ridge 与均匀冠军 TSPO+ 为 100% | 编号与冠军规则会塑造选择，不等于编号偏好必然损害质量 |
| E18 | 2,998 道可评分独立问题 | TSPO_uniform 对 SPO_coordinate 为 +0.011749 个百分点，纠错 377、破坏 376 | 对称处理未显示实际质量增益；该负结果完整保留 |
| E19 / P1 | 原 600 题五折开发分析 | B/C 严格换队 150 题；C−B 为 +1.442 个百分点 | 受控机制与开发结果，不是独立新题评价 |
| E20 / P2 | 2,400 道独立新题 | B 85.355%，C 86.681%，C−B 为 +1.326 个百分点；严格换队 302 题 | 原系统冻结 B/C 策略的独立质量结果；主要收益来自 BBH |
| E21 / P3 | 原池 ListNet 与外部 548 题 | 原池 ListNet 严格换队 135 题、质量差 −0.278 个百分点；外部 TSPO+ / ListNet 严格换队 113 / 41 题、质量差 +0.145 / −0.202 个百分点 | 严格排序变化可扩展，质量方向不一致 |
| E22 | 原 600 题匹配控制 | C 相对三份匹配随机掩码平均，TSPO+ 为 +0.352、ListNet 为 −0.019 个百分点 | 对全并列行定向降权的特殊质量优势证据不足 |

P2 的 raw-exact 敏感性点差为 +0.639 个百分点。这里的 raw-exact 指浮点输出上不使用近并列容差的最大值规则，**不是数学精确最优解或精确 oracle**。主规则在距最大分不超过 1e−8 的动作间均匀分配；其质量按冻结概率计算期望，不把小数纠错次数伪写成单次部署的整数事件。

P3 的 62.194% 对照是**各任务分别用训练区选择固定模型，再对两个任务等权汇总**，不是两个任务共同使用一个全局模型。旧摘要中的 `global_fixed` 命名按执行代码中的任务内语义解释。两个外部主对照的 C 都未超过该任务内固定基线。

E22 显示变化不只来自分数共同平移或参数共同正比例缩放；同时，一般训练行降权也能造成广泛严格换队。动作变化、机制特异性和质量改善是三个不同的证据问题。

## 范围与后续整理

当前最明确的贡献是监督结构、共享参数和路由行为之间的受控机制证据。优势在于端点干预、严格动作变化、数值资格、独立原系统评价以及正负结果共同保留。限制包括原 600 题长期开发复用、原系统仅一套三模型聚合池、有限生成重复、解码规则敏感性，以及外部实验只覆盖单模型选择。

主张与证据表列出写作前仍需核对的复现资产和报告口径。若未来要提出跨系统质量优势或有限反馈采集效率，需要另有对应实验；不把这些目标登记成已经完成的成果。新增汇总不报告置信区间，不为置信区间运行 bootstrap；各历史阶段的原始文件保持其冻结身份。
