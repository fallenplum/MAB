# 有限评测预算下的模型组合路由：E1归档

原E1已完成8800次真实调用；本目录保存固定源代码、配置、原汇总结果及后验问题审计。附带的E2-E5模块属于原共享源码，不能据此认定这些实验已完成。

当前配置尚未证明组合路由的实际收益。强单模型79.5%，校准选出的固定组合69.5%，强三采样再聚合76.5%；同批三采样直接投票82.5%，相对单次的提升区间仍包含零。GSM8K的95%来自100道官方train题，不是官方完整测试集结果。

原结果中的PASS仅检验不可部署的逐题理想上界机会，不是学习成功、成本收益或全项目完成。新增600次聚合器诊断已全部完成、独立于原E1：Qwen2.5放宽输出上限后78.5%，Qwen3融合83.0%，Qwen3同设置独答79.5%，原直接投票82.5%。融合对投票的差值仅0.5个百分点，配对区间[-2,+3]个百分点。候选仍为同一强模型三采样，不能据此证明异构组合路由收益。原在线12000次聚合保持审计暂缓。
