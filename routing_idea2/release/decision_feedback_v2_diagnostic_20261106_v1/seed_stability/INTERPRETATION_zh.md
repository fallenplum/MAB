# 同题跨生成seed稳定性诊断

**仅为既有train600／validation200的事后CPU诊断。没有新模型拟合、LLM调用或答案评分，也没有读取fresh／封存gold或回答。**

## 结论边界

观察到的同题组合差异并非全部来自某一次生成：validation有182/200题存在至少一个组合在三次生成下均正确。但这种事后存在性不足以证明路由器能从未见题输入中找到它。用同题另外两次生成的真实评分选组合，在第三次生成上也尚未稳定优于既有子任务固定组合。

两seed选组合使用了同一道题另外两次生成的真实答案评分，属于事后可复现性检查；部署时未见题没有这些标签，所以它不是可部署路由方法。固定同分规则为组合索引升序；源最优集合均匀破同分的验证准确率为87.97%，也保留于完整报告。

验证集三个留出seed42／137／2024的准确率分别为86%／91%／87%，没有隐藏较差方向。训练集的负差值尤其不能直接推广为未见题结论，因为其固定基线本来就由同一训练集三seed选择。

## oracle机会的可观测分解

验证集逐seed事后oracle为96.17%；为每题选定同一个组合、按三seed平均评分事后取最优，则为95.00%；既有子任务固定组合为87.00%。因此9.17pp的观察到oracle机会可代数分成8.00pp的跨生成共用组合事后部分，以及1.17pp的逐生成换组合额外部分。前一部分仍使用了所有三seed结果进行选择，仍可能过拟合；这不是“87.27%可学习稳定信号、12.73%真实噪声”的估计。

另一种更严格的观察口径：55个可以被当seed oracle纠正的固定基线错误(q,seed)中，33个来自存在三seed全对组合的题，22个来自没有这种组合的题。它与上一代数分解回答的问题不同，不应混用。

## 风险与证据范围

- S2训练成员三seed及所有聚合均为匹配A6000环境。验证seed42中400条Qwen／Coder成员回答复用了本机历史输出，因此涉及42的比较混合生成seed与成员平台；137↔2024为同A6000比较。
- 只有三次生成，mixed score模式占比（validation为15.925%）不能解释成真实噪声比例。每个BBH子任务仅3或4道验证题，完整27任务统计和支持数全部保留，但不据多重事后对比作机制成立主张。
- 优点是无需新增生成，即可区分事后机会、同题跨生成复现和可部署未见题泛化。局限是它无法替代独立fresh检验，也不证明当前输入特征能学到稳定组合选择。
- 所有结果为探索性、未做多重比较校正；不据此启动新聚合、恢复生成或扩大Stage3。
