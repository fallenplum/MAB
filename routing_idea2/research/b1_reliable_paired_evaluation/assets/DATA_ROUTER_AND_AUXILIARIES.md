# B1 数据、冻结系统与历史辅助预测

## 研究问题

本模块固定一个逐题组合路由器和一个全局默认组合，准备有限题池配对评估的可见输入。后续采样只改变购买哪些问题的反馈。

## 数据角色与来源

历史监督使用原 V2 `selector_train` 600 题，GSM8K 与 BBH 各 300 题。待评估题池使用原 V2 `selector_validation` 200 题，两任务各 100 题，保留三个生成重复 42、137、2024。

输入包只含问题 ID、规范化哈希、任务元信息及冻结 MiniLM 向量。模型路由和辅助预测均不使用真实任务或 BBH 子任务标签。任务元信息仅供历史交叉拟合分层与最终分组统计。

原分区元信息显示 `selector_validation` 对应 `online_calibration`，200 个 ID 全部匹配。早期聚合器诊断 200 题对应 `e1_diagnostic_evaluation`，与本题池的 ID 交集为 0。train600 与 validation200 的 ID 和规范化哈希交集均为 0。

该 200 题已用于历史开发，本轮有限池回放的真值范围固定在这批问题和三个已执行生成重复。新题总体泛化需要额外的独立证据。

## 冻结默认与候选

默认组合仅根据 train600 的三重复平均真实奖励选定。按六选三的字典序编号，默认动作索引为 5，成员索引为 0、2、4。

候选使用历史 `direct20__pca16__a100` 的完整 train600 权重。原状态包仍可恢复，恢复源为既有 `FITTED_CANDIDATE_STATES.pkl`。历史训练内选择文件预先选中了该配置，本轮直接恢复其 PCA、标准化和 17×20 参数矩阵。

- PCA 保留 16 维，随后做训练区标准化，并加入受正则惩罚的常数输入。
- 原目标在三个单独生成奖励上使用 alpha100。改写为每题三重复均值时，等价 alpha 为 100/3。
- 直接预测 20 个组合的绝对评分，取 NumPy 精确 `argmax`，并列按组合字典序选首项。
- 原权重与独立闭式核验的最大预测差为 2.89e-15。
- 单独重复损失与均值损失的等价核验最大误差为 2.22e-15。

200 题中，候选与默认在 184 题选择不同，在 16 题选择相同。相同动作共用同一执行结果，其配对差值严格为 0，辅助差值、预计增量评估成本和需要购买反馈的概率均可为 0。总体均值仍使用 200 题分母。

## 历史配对残差与二阶矩预测

辅助均值使用冻结路由器对候选与默认的预测分数差，裁剪至 [-1,1]。

历史标签采用原 600 题的五折问题级交叉拟合。每折只用其余 480 题拟合 PCA、标准化、直接20 Ridge，并选择该训练区的全局默认。被留出问题的组合选择完成后，才用其真实奖励计算三重复平均配对差及预测残差。

二阶矩预测器使用固定 alpha100 的 Ridge，预测配对残差平方及原始配对差平方。输入由 384 维问题向量、20 个预测分数、两组合身份和成员指示、重叠数与辅助均值组成，共 458 维。仅使用发生动作分歧的 549 个历史 OOF 问题拟合，标准化只拟合这些合法历史行。

没有进行辅助模型超参数搜索。残差二阶矩预测裁剪至 [1e-6,4]，原始配对二阶矩裁剪至 [1e-6,1]，结构性零区域单独置 0。

辅助诊断额外使用外层五折、每个外层历史区内部再五折的嵌套交叉拟合。外层评价题的奖励没有参与其路由器、默认、辅助标签构造或辅助模型拟合。

## 历史费用模型与执行复用

费用预测只根据 train600 中每个成员和每个组合的真实历史平均 Token 及源执行墙钟构建。对一个不同动作的配对反馈包，三个生成重复分别执行两组合成员并集及两个不同聚合。共同成员仅计一次。

- 每题标准答案揭示 1 次。
- 每题成员调用为 3×成员并集大小，对应 12、15 或 18 次。
- 每题组合聚合 6 次，最终输出判分 6 次。
- 总 Token 为输入与输出 Token 之和，费用均值只来自历史题。
- 同动作区域使用已知零增益权限，额外评估费用为 0。

冻结动作下，184 个非零反馈包全部执行的预计总 Token 为 2,172,747.52，成员调用 2,511 次，聚合调用 1,104 次。预计每包 Token 最小 10,896.46，最大 12,693.47，变异系数 0.04042，最大与最小之比 1.1649。费用异质性较小，需要由后续实际比较检查双预算分配的独立价值。

当前题池的实际输出长度与真实费用由后续独立评价器保管。费用预测满足期望约束的含义需与最终实际资源使用分布共同报告。源执行墙钟为已有 `model.generate` 用时的加和。

## 优势与风险

恢复原完整权重、按题交叉拟合辅助标签、冻结前隔离评分以及显式成员并集计费，使各采样规则能够共享同一套评估对象和权限。模型恢复、目标缩放和数据身份的核验均可逐项重放，证据置信度高。

历史 OOF 残差来自训练规模 480 的同一预测器配方，与完整 600 题拟合后的对象存在训练规模差异。只有三个生成重复，辅助二阶矩预测失准，预计费用异质性较小。上述因素都会影响主动分配的效率，应通过真实有限题池误差和覆盖率检验给出结果。

## 下一步

独立评价器按已冻结的两动作读取配对真实反馈，计算固定题池真值。采样器仅接收已购买的反馈，所有方法共享同一冻结输入、费用预测与结构性零权限。是否存在有效的精度—完整成本改善，由后续配对模拟结果决定。
