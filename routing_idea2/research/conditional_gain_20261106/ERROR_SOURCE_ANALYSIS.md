# 基础价值预测器与错误来源

## 研究问题
结构容量、输入信息和决策损失哪个限制服务质量。

## 数值结果与统计结论
原二阶PCA16训练OOF86.44%，扩到完整向量+元数据直接20为86.78%，但后者val84.33%，原二阶val85.67%。低秩5与排序val各86.50%，仍低于subtask87%。条件MLP的OOF提升没有稳定迁移到val。

## 失败原因
1. 无法表达的5个组合方向只解释一部分经验对比残差，真实条件残差还混有三seed噪声。
2. PCA增维降低训练拟合限制，却扩大方差；当前负迁移不足以单独证明PCA是主因。
3. 600不同题对完整向量、默认条件交互及32隐藏单元的容量有限；同一BBH子任务仅11–12个训练题。
4. 主候选GSM净+2、BBH净−7题×seed实例；小子任务CI不能支撑稳定内部选择规律。
5. 标签相对化的普通线性模型严格等价，已有真实OOF检查；新收益必须来自条件表示、非线性或阈值，且这些本轮未证实泛化。

## 推荐与下一步
作为可解释基础诊断，保留原二阶与直接20/PCA16双基线，低秩和排序作容量/目标对照；不把任一val最高模型重新选为主模型。训练OOF冻结的主候选仍为MLP+metadata/tau.025，但不能称作已经具有可重复增益的推荐部署器。后续若需另立方案，应先修正过度切换并另行约束搜索，不能继续用val挑赢家。
