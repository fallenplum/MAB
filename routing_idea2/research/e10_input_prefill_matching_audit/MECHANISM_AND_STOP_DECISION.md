# E10 机制解释与预声明研究决定

## 决定

**STOP_FIXED_PREFILL_PCA16_RIDGE。** 原池 Qwen3-8B 固定第24层末输入 token、PCA16、经验均值 Ridge 候选未通过预声明 GO。点差+1.0556pp达到预算门槛，普通95%配对区间[−0.3333,+2.4444]pp跨零，fine 匹配相对 A 减少0.1907pp，主模型低于三控制平均0.5370pp。停止范围限定到此固定方案。

所有效用结果属于 `EXPLORATORY_REUSED_TRAIN600`。结果、统计和最新成本字段已逐项核对，运行独立复核以其单独收据记录。

## 第一性原理问题

组合路由需从输入预测同题不同最终聚合动作的奖励差异。P1 固定已选动作，通过保持每组动作使用次数的精确期望测量匹配。P2 保持原经验均值监督与简单头部，测试原池 Qwen3-8B 的固定 prefill 表征。模型正确率探针与组合动作效用的对应关系需由本项目实际结果建立。

## P0 对输入解释的约束

旧256 token 链确有6题截断，其中GSM8K为0题，BBH为6题。真实 tokenizer 的 offset 和 token ID 资格支持旧可见前缀复原。600题旧 MiniLM 缓存经原 encoder 类在 CPU 全量重放，向量逐 bit 相同。`INPUT_COVERAGE_AUDIT.json` 初版与追加的 `INPUT_COVERAGE_AUDIT_COMPLETION.json` 均保留，CPU 完成证据以补充收据为准。

R_full−A 测量完整输入链的联合替换。R_match−A 测量经旧可见原文对齐后的表征替换，R_full−R_match 描述新表征下的输入覆盖变化。六题截断子集只作预声明描述。P0 的确定性映射证据置信度为高，历史 E1–E9 负结果的截断归因仍保留未知。

## 三个证据层级与置信度

**本次实际计算且可私有重放的证据**包括 P0 全量输入审计、P1 精确分解、prefill 合成资格和P2统一评价。对现有点值、普通区间和冻结门槛判断的置信度为高，依据为冻结来源与可核对计算收据。对跨独立样本正收益的支持仍受区间和重复开发限制。

**公开汇总、代码和哈希支持的记录**包括 E9 冻结基线、两次评分重放以及追加时间说明。原始 review 的开始、完成缺失，完整重新拟合的执行证据仍为空。对已核对记录范围的置信度为高。

**机制推测和未来待验证假说**包括表征在其他配置下能否捕获题目特异动作差异、六题输入覆盖的总体效用贡献、独立样本收益及实际 ROI。当前外推置信度为低，依据为fine相对A和内容条件未通过，以及历史数据重复开发的限制。

## 优势与劣势（风险）

**优势**为评价分解与固定候选相衔接、原 token 边界可复核、旧输入精确重放、五项门槛预先固定，并把真实 prefill 成本列入决定。

**劣势（风险）**为 fine 小组可重排空间有限、单动作组占有实际支持、PCA16 与单层选择可能压缩有效信息、量化与硬件配置限制可迁移性，以及旧600题多轮开发造成的选择偏差。内容控制只有三个固定种子，承担敏感性证据。普通区间条件于已拟合开发模型，外部确认仍是后续问题。

## 拓展思考与后续权限

当前决定为停止该固定候选，缺少进入细粒度路由独立确认设计的资格。停止范围为本轮完整输入链、原池 checkpoint、固定第24层、PCA16与Ridge配置。其他表征或所有question-only路由的可学习性仍属开放问题。

若未来出现独立授权的新研究问题，候选、比较、效应目标、功效和数据权限需在该研究协议中明确。当前结果与预声明门槛共同决定本轮停止范围。
