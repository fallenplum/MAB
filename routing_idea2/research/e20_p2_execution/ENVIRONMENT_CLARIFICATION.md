# P2编码环境说明

E20公开requirements采集了D盘通用训练头与数值审查环境的版本，其中transformers与tokenizers版本不能用于恢复原冻结MiniLM编码环境。原编码过程具有独立的严格版本核验，其私有收据提供实际执行依据。

P2已在正式前向计算前识别该环境差异。D盘启动被版本守卫拒绝，前向次数为0。正式2400题编码使用原E盘虚拟环境，版本如下。

| 依赖 | 正式编码版本 |
|---|---|
| NumPy | 1.26.4 |
| SciPy | 1.11.4 |
| scikit-learn | 1.7.2 |
| PyTorch | 2.4.1+cu121 |
| Transformers | 4.51.3 |
| Tokenizers | 0.21.4 |
| Safetensors | 0.8.0 |

完整执行信息见P2_ENCODER_ENVIRONMENT.json及私有编码收据。B/C继续使用E20冻结权重和train600预处理状态。服务成员及聚合器使用服务器原E18逻辑模型、生成配置与算子身份，其实际运行环境另外记录。

本说明用于纠正复现依赖的适用范围，原E20提交及实际编码收据继续归档。
