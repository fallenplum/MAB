# train600 机制特异性审计

## 审计结论

**现有结果支持全并列约束通过共享参数改变严格排序。全并列行定向降权的特殊质量优势证据不足。**

TSPO+ 的 C 在同总权重均匀降权之上高 +1.343 个百分点，在三份匹配随机掩码平均之上仅高 +0.352 个百分点，且低于一份预先固定的匹配对照。ListNet 的对应点差为 −0.278 和 −0.019 个百分点。两种损失都产生参数方向与严格动作变化，完整质量影响随降权位置和损失而变化。

## 冻结实验

使用原 train600、原五外折、每折 480 / 120 题、原三个生成重复、同一 17×20 线性头、原折内特征和正则。B/C 共 20 个已冻结头直接复用。为了取得 TSPO+ 的合法对偶次梯度，另外对同一目标恢复 10 次 B/C 求解，核对中心化预测一致。控制只改变训练行权重，分母始终为 480。

| 条件 | 权重规则 |
|---|---|
| B | 每题权重为 1 |
| C | 全动作经验均值完全相同的 T 行为 0，其余为 1 |
| Uniform | 每题为 (480−数量T)/480 |
| Matched 三种子 | 匹配分层内随机置零，与 C 在每层置零数一致 |

匹配分层由任务／BBH 子任务和输入特征范数中位数二分构成，共 56 层。抽样按固定种子与原题哈希排序，两个损失使用完全相同的掩码。种子固定为 2026111801、2026111802、2026111803。真实子任务只用于审计的匹配设计。所有新模型与掩码在本轮读取外折奖励前完成冻结。

各折 T 为 244、240、245、241、254 题。四折非 T 少于 T，同数量且全部来自非 T 的二值置零对照无法实现。本轮匹配掩码同时置零 T 与非 T，仍保留 31.0%–38.3% 的 T 监督。每折有 63–83 道题处在纯分层中，其随机掩码位置由层约束固定。匹配控制了训练权重总量、任务分布与范数分箱，题目难度和完整特征仍有差异。

## 质量对照

主解码沿用 tau=1e−8 均匀 argmax。表中质量是三个生成的题级平均，再给 GSM8K 和 BBH 各 50% 权重。

| 条件 | TSPO+ 准确率 | ListNet 准确率 |
|---|---:|---:|
| B | 85.058% | 85.944% |
| C | 86.500% | 85.667% |
| Uniform | 85.157% | 85.944% |
| Matched 2026111801 | 87.000% | 86.278% |
| Matched 2026111802 | 85.833% | 85.000% |
| Matched 2026111803 | 85.611% | 85.778% |
| 三匹配对照等权平均 | 86.148% | 85.685% |

三掩码等权结果对应预先固定重复的平均，没有选择最佳掩码。C 对该平均的配对纠错与破坏期望在 TSPO+ 上为 63.000 / 56.667 次，ListNet 为 47.667 / 48.000 次。小数来自冻结策略耦合及三掩码的平均。三个生成 seed 的 TSPO+ 点差分别为 +0.722、+0.944、−0.611 个百分点，ListNet 为 −0.278、+0.167、+0.056 个百分点。

相对三掩码平均，TSPO+ 的 GSM8K / BBH 点差为 +0.111 / +0.593 个百分点，ListNet 为 +0.407 / −0.444 个百分点。全任务、27 个 BBH 子任务、生成重复、折和 raw-exact 结果全部保留在 `RESULTS.json` 与 `SUMMARY.json`。

## 特异性与参数几何

Uniform 相当于把整体数据项乘以同一个 s，等价于全权重目标使用 λ/s 的相对正则。它控制了纯监督总量效应。相对 B，Uniform 在 TSPO+ / ListNet 上仅有 3 / 2 道严格换队；C 为 150 / 135 道。原均匀降权不能解释全部严格排序变化。

三份匹配随机控制的严格换队数在 TSPO+ 上为 137、143、149，在 ListNet 上为 327、321、314。一般训练行降权同样能产生广泛动作变化。变化题数本身无法区分特殊的全并列机制和训练信息重新分配。

在 B→C 的全部十个单元中，J_T 上升，参数范数和间隔增加，且存在可量化的参数方向改变。TSPO+ 最佳正比例缩放后的残差占 C 范数 76.0%–87.4%，ListNet 为 23.7%–34.4%。因此这些动作差异包含超出共同缩放的变化。全并列梯度与其他训练行响应高度抵消，具体推导、数值与分量解释见 `GEOMETRY.md`。

## 对最终主张的影响

本轮允许写入的主张为

> 在固定表示、函数类与正则下，经验全并列样本施加的对称损失项能够改变共享参数方向，并改变其他题目的严格动作排序。训练行降权的实际质量影响依赖损失与数据分布。

质量特异性的证据仍有限。TSPO+ 相对匹配对照平均的差值较小且有 seed 反向，ListNet 没有对应优势。三个预固定掩码提供描述性机制对照，旧 train600 已反复用于开发，五折训练历史重叠，独立题数始终为 600。P2、P3 的历史结论和数值继续保留。
