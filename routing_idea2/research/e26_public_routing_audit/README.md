# E26 · 公开组合路由的并列审计

**结论**　SkyLLM 的固定三成员质量估计适配有真实的最高分并列。将训练全并列题的贡献归零后，组合排序、最高分支持和同一规则下的实际选择完全一致。因此，这个干预的准确率影响严格为零。另加解码规则可改变选择，属于部署敏感性。E26 在输入与预测检查阶段结束，新增成员生成、聚合和 Token 均为 0。

## 核对的公开方法

SkyLLM 用 all-MiniLM-L6-v2 的 384 维向量按 L2 检索，按近邻中各模型子集的正确率估计新题上的子集质量。论文设定近邻数为训练题量的 10%。质量估计直接做均值，没有拟合 SPO+ 式的全并列压缩项。原系统候选为全部非空子集，使用投票或概率融合，并在成本和时延预算下做跨题的 Pareto 剪枝与分组背包优化。Algorithm 1 的等值更新保留当前状态。论文未固定候选遍历顺序和等距邻居的处理，当前可查的原始来源亦未找到可核验的作者实现和冻结输出。[SkyLLM 原论文 §3.2–3.3、§4、§5.1](https://aclanthology.org/2025.findings-acl.1073.pdf)

本次复算保留原质量估计公式及 10% 邻域。用 MAB 现有 MiniLM 向量和 V2 聚合正确率，固定 20 个三成员组合。选择部分取双预算均不绑定且每道题派出一支组合的逐题最高分特例。原生 DP 允许不分配，具有不同的全局可行域。复算的最高分精确并列按已冻结的 MAB 动作顺序取第一个，属于本次适配声明的规则。源论文给出了不同预算下的结果，E26 的数字对应 MAB 题池上的估计器适配。

## 同规则干预

训练记录先将同题三次生成汇总为每动作的整数成功数。干预只归零同题所有动作成功数完全相同的近邻贡献，保留相同邻域、权重、分母和推理规则。若全并列行的奖励为 \(c_i\mathbf 1\)，其差正好是

\[
q_{\mathrm{original}}(x)-q_{\mathrm{muted}}(x)
=\frac{\sum_{i\in N(x)\cap T}c_i}{|N(x)|}\mathbf 1.
\]

这里的 \(c_i\) 是三次生成平均。全部动作间距、中心化分数、排序以及相同解码下的动作均保持一致。全批次若强制恰好为每题选择一个组合且成本和时延固定，这个偏移在所有可行解上给目标加同一个常数。允许跳题时常数会随入选题变化，结论止于上面的逐题质量估计与声明的部署。

- train600 的 579 题有多个经验第一，306 题的 20 个组合全部并列。
- 历史五折每折以 480 题作近邻库、120 题作留出，取 48 个近邻。600 道留出题有 228 道预测精确并列，每一折的排序与选队变化都是 0。数据属于历史开发资产。
- E24 复用 1,196 道题的输入向量，全量 train600 提供 60 个近邻。381 题预测最高分精确并列，815 题唯一最高分。最小正间距为 1/180，\(0<\mathrm{margin}\le10^{-8}\) 的题数为 0。全并列干预使 1,196 题的绝对分数共同平移，中心化分数、排序、选择变化均为 0。精确最高分支持的核验用整数完成。

## 准确率差能有多大

给定同题选择分布 \(p_x,q_x\)，任意组合正确率向量 \(r_x\in[0,1]^{20}\) 满足

\[
|(p_x-q_x)^\top r_x|\le \tfrac12\|p_x-q_x\|_1.
\]

原因是这个系数向量总和为零，正系数之和与负系数绝对值之和相等。确定性策略的右侧就是是否选不同组合。同题三个生成仍按题汇总。用原题权重平均右侧可得到总体百分点绝对上限。交互差先合并四个分布的正负系数再计算，避免重复计数。上限给定分数与动作分布，只使用奖励在 0 到 1 之间这一条件。

| 同一 E24 输入题池 | 动作分布变化题数 | 准确率差或交互绝对上限 |
| --- | ---: | ---: |
| SkyLLM 适配，归零全并列贡献，固定解码 | 0 | 0.00 pp |
| SkyLLM 适配，另加均匀与历史优先两套解码 | 381 | 18.04 pp |
| E25 MLP 1701，训练 × 部署交互 | 0 | 0.00 pp |
| E25 MLP 1702，训练 × 部署交互 | 504 | 31.16 pp |
| E25 MLP 1703，训练 × 部署交互 | 467 | 28.99 pp |

SkyLLM 适配的 18.04 pp 只表示另行更换解码有改变正确率的空间，方向和实际大小未知。MLP 1701 的 U/P 分布完全相同，补评分也无法改变这个种子的部署交互。其 B/C 在同一部署下的质量差属于另一个问题。1702/1703 及线性头的输入侧上限见 [RESULTS.json](RESULTS.json)，上限大小本身无法判断实际效用。

## 停止判断与复现

**通过的诊断**是较多经验并列可与零训练干预效应同时出现。检查其他路由器时，先看全并列行对中心化得分是否施加约束，再量化实际部署分布发生了多少变化。共同偏移可以通过中心化分数识别，部署准确率差的最大空间可在生成前由策略差异算出。结论覆盖这一个近邻估计器的固定评分适配，完整双预算路由的动作身份和服务质量仍未核验。

同解码对照的效果精确为零，且额外解码属于敏感性诊断。因此本轮没有扩充评分并集，未开启 Ridge、固定组合与新策略之间的质量排名。未读取 E24、fresh400 或 sealed200 的评价成绩，未新增拟合。结果保留五折与任务分解、已有 E25 三个 MLP 种子及三档线性头、私有输入包指纹和实际新增成本。

使用 Python 3.11.14、NumPy 1.26.4、SciPy 1.11.4、scikit-learn 1.7.2。用同一分支中 E19 与 E24 的脚本和协议，指定已有私有工件的根目录与一个新输出文件。
