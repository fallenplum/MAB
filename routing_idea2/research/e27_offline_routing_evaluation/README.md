# E27 · 五折实际准确率复算

用历史 train600 的 20 个组合 × 三次生成真实评分，比较固定三成员 SkyLLM 适配的三种解码，以及折内训练的 Ridge、固定最佳组合和神经 ListNet。600 道题各评价一次，GSM8K 和 BBH 各占 50%，BBH 内按题平均。每题的三次生成先在题内汇总。所有数字属于历史开发集的五折结果。

## 神经 ListNet

用同一折内的 MiniLM、PCA16 和标准化特征训练 16 单元 tanh 隐层的 ListNet 头。正常目标按题计算由真实经验奖励 softmax 决定的 top-one 交叉熵。成对干预只将 20 个动作经验奖励全相同的训练行权重置零，继续使用原 480 题分母、同一初始化、同一正则和同一推理规则。每个设置以三个初始化重复，优化只见本折历史。ListNet 的原始目标和神经训练见 [Cao 等](https://www.microsoft.com/en-us/research/publication/learning-to-rank-from-pairwise-approach-to-listwise-approach/)。此处为 20 个组合动作的适配。

两支在所有初始化的 600 道题上都有唯一最高分动作。保留全并列行时，其均匀目标的训练 KL 和每折的留出最高分间隔中位数均较小。屏蔽后严格换队超过一半，准确率差跨初始化变号。六个神经策略的总体点值均高于同题 Ridge 和固定组合。完整的配对差、任务、子任务、生成种子和外折分解见 [RESULTS.json](RESULTS.json)。

论文可据此指出，全并列监督在一个独立于 TSPO+ 的神经训练目标中也改变了明确首选的组合。现有结果支持报告训练干预的排序效应和初始化依赖。近并列解码交互在这六个神经策略中无从触发。本轮固定了神经架构和正则，性能水平限定于这些配置和历史题池。

## 复现

使用 Python 3.11.14、NumPy 1.26.4、SciPy 1.11.4 和 scikit-learn 1.7.2。先运行 `fit` 写出私有冻结预测，再用 `evaluate` 复算公开结果。两步共用该分支中的 E19、E20 和 E26 工具，并引用私有资产中的原 E8 特征算子与内折记录。

```powershell
$entry = "routing_idea2/research/e27_offline_routing_evaluation/run.py"
$assets = "<private asset root>"
$privateRun = "<new private run directory>"
python -B -X utf8 $entry --phase fit --asset-root $assets --private-root $privateRun
python -B -X utf8 $entry --phase evaluate --asset-root $assets --private-root $privateRun --output E27_REPLAY.json
```

训练调用 50 次 Ridge 闭式拟合和 30 次神经头拟合，保留全部种子，梯度检查最大误差为 9.59×10⁻¹¹。新增成员生成、聚合、编码器前向及 Token 均为 0。随机策略的纠错和破坏是在共享同动作概率质量下的期望次数，净值等于两策略的准确率差所对应的正确生成记录差。训练配置见 [PROTOCOL.json](PROTOCOL.json)，结果 JSON 含冻结哈希和每次拟合的数值资格及耗时。
