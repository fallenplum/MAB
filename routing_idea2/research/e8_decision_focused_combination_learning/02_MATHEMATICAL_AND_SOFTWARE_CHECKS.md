## A1 原直接20组合Ridge恢复

原 `direct20__pca16__a100` 保存了完整600题的OOF预测。各折独立权重由其原始训练配方重建，并逐项对照既有预测。

原特征由冻结384维MiniLM向量进入历史区拟合的PCA16，再做历史区标准化，最后加入受正则惩罚的常数输入。20个动作各有独立线性头。

令每题三重复均值为 \(\bar Y\)，原始重复目标为

\[
\sum_{q,\ell=1}^{3}\|\phi_qW-Y_{q\ell}\|_2^2
+100\|W\|_F^2.
\]

使用重复均值时，等价的可优化部分为

\[
\sum_q\|\phi_qW-\bar Y_q\|_2^2
+\frac{100}{3}\|W\|_F^2.
\]

重复内方差给出与参数无关的加项。因此以三重复均值拟合时，正则系数应为100/3。

| 核验项 | 数值 |
|---|---:|
| 原600题OOF正确率 | 85.277778% |
| 三个生成重复正确率 | 84.666667%、85.333333%、85.833333% |
| 重建与原预测最大绝对差 | 4.33e-15 |
| 原始三重复目标与均值目标预测最大差 | 2.82e-15 |
| 原OOF选队变化题数 | 0 |
| 原OOF最小预测Top-1间隔 | 8.35e-6 |

该OOF结果的统计范围是600题开发交叉验证。历史验证200题的86.333333%属于另一批题。

选队沿用原NumPy精确 `argmax`，完全并列取字典序首组合。全零20分数选择动作0，动作1仅高1e-12时选择动作1。曾使用1e-10近并列容差的另一历史实现，在后一个例子会选择动作0。E8实际服务选择使用原精确规则，并保留数值容差作为软件核验尺度。

## A2 中心化与190等权平方差值的等价性

设动作数 \(M=20\)，中心化矩阵 \(C=I-\mathbf1\mathbf1^\top/M\)。对任意误差向量 \(e\)，有

\[
\begin{aligned}
\sum_{i<j}(e_i-e_j)^2
&=M\sum_i e_i^2-\left(\sum_i e_i\right)^2\\
&=M\|Ce\|_2^2.
\end{aligned}
\]

原绝对价值参数可分为 \(W=W_C+W_\parallel\)，其中 \(W_C=WC\)，共同偏移分量 \(W_\parallel=W\mathbf1\mathbf1^\top/M\)。相同各向同性Ridge惩罚与相同题权重使两部分正交分离。中心化目标的最优解保留绝对Ridge的 \(W_C\)，共同偏移部分为0。组合两两分差与理想精确排序保持一致。

合同M3在权重全1时使用

\[
\frac1n\sum_q\frac1{20^2}\sum_{i<j}
\big[(q_i-q_j)-(\bar Y_i-\bar Y_j)\big]^2
+\lambda\|W\|_F^2.
\]

该目标等于 \(\sum_q\|C(q-\bar Y)\|^2/(20n)+\lambda\|W\|^2\)。与原重复损失匹配的正则系数为

\[
\lambda_0=\frac{100}{3n\cdot20}.
\]

480题时为0.0034722222，320题时为0.0052083333。调参折题数变化时，沿原始重复惩罚尺度换算，避免损失归一改变产生表观提升。

数值核验使用三个带不同正则、非均匀题权重的合成问题，以及全部五个真实480题历史折。190对目标通过显式动作差分矩阵构造完整Kronecker正规方程，独立于中心化闭式解。

| 核验项 | 最大误差或计数 |
|---|---:|
| 平方差恒等式绝对误差 | 2.85e-13 |
| 原Ridge中心化预测与中心化Ridge | 7.50e-16 |
| 显式190对解与中心化解 | 1.84e-14 |
| 三种拟合间精确Top-1变化 | 0 |

**A1与A2均通过。** 正式CPU训练具备原协议恢复及等价性资格。

## A3 参考梯度与小型控制

参考RankNet使用真实非零均值奖励差的符号和绝对大小。按题及190对归一化的参考梯度经过中央差分核验，最大绝对误差1.22e-10。零真实差值的权重为0。

奖励最大化SPO+参考目标为

\[
\ell(q,r)=\max_j(2q_j-r_j)-2q_{j^*}+r_{j^*},
\qquad j^*=\arg\max_j r_j.
\]

任一最大化竞争动作 \(\hat j\in\arg\max_j(2q_j-r_j)\) 给出次梯度 \(2(e_{\hat j}-e_{j^*})\)。其非负性及对实际选队损失的上界来自选择实际预测最优动作后的直接代入。无最大化并列的点采用中央差分，主词典序真实最优与真实最优均匀平均变体的最大误差分别为8.85e-10与8.32e-10。100组额外构造通过真实选队损失上界及次梯度不等式。

|---|---|

### 固定置乱目标的OOF隔离修正

正式冻结前审阅发现，先为拟合区域生成一次置乱目标后，在M3竞争OOF内部再次使用不同置乱映射，会让当前行的置乱目标块出现在其他行的OOF训练标签中。该实现选择已在正式实验前撤回。

修正后，每个合法inner-fit区域先完成子集选择，再在该区域内做一次固定整题奖励块置乱。最终历史拟合区域单独使用一次固定映射。M3对已经置乱的目标数据做普通OOF，持出当前行的对应目标块。以60个合成历史输入做干预，改变持出行的完整三重复×20目标，其自身OOF预测最大变化为0。每个OOF训练标签哈希与相应置乱数据子集严格匹配。

## 优势、风险与下一步

原预测恢复、损失尺度、受罚常数项、字典序并列和候选集合映射均可重放。显式190对解与中心化解分别计算，提供独立的数值检查。资格结论置信度高。

三个真实生成重复提供有限的观测均值。近并列时浮点扰动与精确选择会产生离散敏感性，需要在真实比较中保留选队变化与支持数。小型控制证明程序可以检测指定信号，真实新题收益仍需正式外折评估。

下一步固定内层选择规则与训练目标，冻结全部外折预测后进行独立评价。原始逐题输入、真实评分、模型参数及分折包留在私有目录，公开记录资格配置、哈希和脱敏统计。
